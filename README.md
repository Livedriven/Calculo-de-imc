# 📊 Calculadora de IMC (Índice de Massa Corporal)

Projeto simples de **Calculadora de IMC** desenvolvido com **HTML, CSS e JavaScript puro**, com foco em boas práticas de organização, separação de responsabilidades e manipulação correta do DOM.

O objetivo do projeto é permitir que o usuário informe **peso** e **altura**, obtenha o valor do IMC e visualize a **classificação correspondente**, com mensagens claras e feedback visual.

---

## 🚀 Funcionalidades

- Cálculo correto do IMC
- Classificação automática do resultado
- Mensagens e cores de acordo com a faixa do IMC
- Aceita números com **vírgula ou ponto**
- Validação de entradas inválidas
- Atualização dinâmica do resultado sem recarregar a página

## 📐 Como funciona o cálculo

O IMC é calculado utilizando a fórmula:

IMC = peso / (altura²)


A partir do valor calculado, o resultado é classificado em uma das faixas:

- Abaixo do peso
- Peso normal
- Sobrepeso
- Obesidade Grau I
- Obesidade Grau II
- Obesidade Grau III
